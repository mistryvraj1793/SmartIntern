# 🚀 Smart-Intern Web Application

A full-stack internship management system developed using Java, Spring Boot, Hibernate, and MySQL. This platform helps students, colleges, and companies manage internships efficiently through a centralized system.

---

## 📌 Features

- 🔐 User Authentication & Authorization (Spring Security + JWT)
- 🔗 REST API Integration
- 👨‍💼 Admin Dashboard with analytics
- 🎓 Student Module (Apply & Track Internships)
- 🏢 Company Module (Post & Manage Internships)
- ☁️ Cloudinary integration for file uploads
- 📧 Email notifications using JavaMail API
- 💳 Payment integration (Authorize.Net)

---

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot, Hibernate  
- **Database:** MySQL  
- **Frontend:** JSP, HTML, CSS  
- **Security:** Spring Security, JWT  
- **Tools:** Cloudinary, JavaMail API
